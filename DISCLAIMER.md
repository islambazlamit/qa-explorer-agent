## It is an AI agent, so check its work

The agent can make mistakes, click the wrong thing, or misread a page. Start on a local or test copy of your system, use test accounts, and keep backups. Review each report before you act on it.

## Safety rules built into the agent

The agent is written to ask for the target environment first, use test data with a `QA-` prefix, never enter real payment details, never bypass CAPTCHAs, and never type passwords for you.
